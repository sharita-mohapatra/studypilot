
# StudyPilot

An exam preparation planner designed to help students organize their syllabus, create study schedules, and track their learning progress.

## Features

- Generate a date-by-date study timetable.
- Organize syllabus topics by difficulty.
- Schedule daily revision and practice.
- Track completed topics and study progress.
- Responsive interface for desktop and mobile.

## Built With

- Next.js
- React
- TypeScript
- Tailwind CSS

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

### 3. Open the application

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## Project Status

StudyPilot is under active development. Features and functionality will continue to improve.
